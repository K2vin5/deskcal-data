이런 걸 할 수 있어요

  • 바탕화면 위젯 — 아이콘과 같은 층에 붙어 Win+D 를 눌러도 사라지지 않고, 다른 창 뒤에 가려집니다. 배경 투명도 조절.
  • 공휴일·대체공휴일·24절기 — 한국천문연구원 특일 정보 기준, 자동 갱신.
  • 일정 · 기간 일정 · 할 일 — 날짜 더블클릭으로 바로 입력, 끝내지 않은 할 일은 오늘 칸으로 따라옵니다.
  • 스티커 메모 — 여러 장, 체크리스트, 다크 모드.
  • 외부 캘린더 함께 보기 — 구글 캘린더, 아이클라우드, ICS 주소 (읽기 전용).
  • 가볍게 — 가만히 있을 때 CPU 거의 0, 메모리 약 50MB.

다운로드

최신 버전 받기 (Windows) 설치 안내 보기

릴리스 페이지의 DeskCal_x.y.z_x64-setup.exe 를 받아 실행하세요. (회사 PC 등 MSI 가 필요하면 .msi)
설치하면 앱이 하루 한 번 새 버전을 확인하고, 알림을 누르면 업데이트됩니다.
설치할 때 "Windows의 PC 보호" 창이 뜨면 → 이렇게 하세요.

베타 안내

  • 아직 다듬는 중이라 버그가 있을 수 있어요. 데이터는 하루 한 번 자동 백업되고(최근 7개), 설정 → 일반에서 복원·내보내기를 할 수 있습니다.
  • 앱을 지워도 데이터는 남습니다. 완전히 지우려면 제거할 때 "애플리케이션 데이터 삭제하기"를 체크하세요.
  • 불편한 점·아이디어는 달력 ☰ 메뉴 → 피드백 보내기로 알려 주세요.
