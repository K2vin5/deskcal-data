설치 안내

1. 설치 파일 받기

최신 릴리스에서 DeskCal_x.y.z_x64-setup.exe 를 받습니다.

브라우저가 "흔히 다운로드되지 않는 파일" 이라고 하면 ⋯ → 유지 를 누르세요. 베타라 다운로드 수가 적어서 나오는 안내입니다.

2. "Windows의 PC 보호" 창이 뜨면

DeskCal 은 아직 유료 코드 서명 인증서가 없어서, 처음 실행할 때 Windows SmartScreen 이 아래 창을 보여 줍니다. 바이러스라는 뜻이 아니라 "아직 잘 알려지지 않은 앱"이라는 뜻입니다.

  1. 파란 창에서 추가 정보 글자를 누릅니다.
    스크린샷 자리 — "Windows의 PC 보호" 창의 추가 정보
  2. 아래에 생긴 실행 버튼을 누릅니다. (게시자: 알 수 없음 으로 나옵니다)
    스크린샷 자리 — 실행 버튼
  3. 설치 프로그램에서 다음 → 설치. 설치가 끝나면 바탕화면 오른쪽 위에 이번 달 달력이 나타납니다.

설치 파일은 GitHub Releases 에서만 받으세요. 다른 곳에서 받은 파일은 실행하지 마세요.

3. 처음 실행

  • 짧은 사용 안내가 뜹니다 (정보 탭에서 다시 볼 수 있음).
  • 작업 표시줄 오른쪽 아래(트레이)에 달력 아이콘이 생깁니다. 달력의 ☰ 버튼이나 트레이 아이콘으로 설정을 엽니다.
  • Windows 를 켤 때 자동으로 시작하려면: ☰ → 설정 → 일반 → "Windows 시작 시 자동 실행".

업데이트 · 제거

  • 새 버전이 나오면 달력 위쪽에 알림이 뜹니다. 눌러야 설치되고(강제 업데이트 없음), 설치 전에 데이터를 자동 백업합니다.
  • 제거: Windows 설정 → 앱 → 설치된 앱 → DeskCal → 제거. 데이터는 기본으로 남고, 지우려면 "애플리케이션 데이터 삭제하기"를 체크하세요.
